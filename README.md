# CNX_Countting

## Thông tin siêu dự án

Dự án hướng đến nghiệp vụ kế toán dịch vụ quy mô lớn, với các định hướng chính:

- **Giao diện**: sử dụng **Radzen** để thiết kế UI.
- **Chuẩn màu sắc**: ưu tiên tông **xanh đậm/đen** kết hợp **cam**.
- **Nền tảng kỹ thuật**: thiết kế API theo kiến trúc chuẩn **.NET 8**, ngôn ngữ **C#**, phát triển trên **Visual Studio**.
- **Cơ sở dữ liệu**: sử dụng **SQL Server** để quản trị dữ liệu.
- **Bảo mật & phân quyền**: có **1 database master** để cấu hình hệ thống, lưu trữ thông tin phân quyền và xác thực (authentication) trước khi cho phép truy xuất dữ liệu và xác định thao tác được phép trên dữ liệu đó.
